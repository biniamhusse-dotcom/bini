Configuration Switches & Rules

Enable Main Diagnosis Feature
Display the dedicated Main Diagnosis highlight box on the clinical Consultation Diagnosis tab.
Make Main Diagnosis Mandatory {{ config.isMandatory ? 'ENFORCED' : 'OPTIONAL' }}
Mandatory: Doctors cannot save the consultation without selecting a Main Diagnosis. Unmandatory (Optional): Doctors can save consultations without a Main Diagnosis. If left empty, information saves smoothly.
Occurrence Mandatory (New / Repeat)
When enabled, doctor must select Occurrence (New or Repeat) when a Main Diagnosis is provided. When disabled, Occurrence is optional.
Allow Non-Coded Free Text Entries
When OFF (recommended for ICD compliance), doctors must pick from coded terms. When ON, free-text entries can be saved directly.
Enforce Single Primary Diagnosis
Only one Main Diagnosis per encounter. Any additional diagnoses are automatically categorized as Secondary.
Default Code Filter on Diagnosis Tab
Select which code system button is pre-selected for clinicians when opening the Diagnosis consultation screen.
